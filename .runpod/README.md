# Flux Image ComfyUI One-Click

See the [repository README](https://github.com/acdevmedia/comfyui-flux#readme) for the generations, variants, GPU requirements and environment settings. The default is **FLUX.2 dev, which needs an 80 GB GPU**; set `MODEL_MODE=turbo` for Klein 4B on a 48 GB card. FLUX.1 and FLUX.2 need no Hugging Face token; only the `:3` (FLUX 3) tag does. Hub uses the same Dockerfile and defaults as the Pod template. Use one active worker for stateful browser sessions.
